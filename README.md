# 🪐 io.com.ly - AI Canvas Studio

تطبيق الصفحة الواحدة (SPA) المطور والمبتكر لتحويل الشخبطات والرسوم الهندسية البدائية إلى لوحات وتصاميم واجهات مستخدم حية ومباشرة باستخدام قوى نماذج **GroqCloud**.

## 🚀 الميزات الفنية الحالية
- **لوحة رسم هندسية متطورة**: دعم الرسم الحر، الخطوط المستقيمية، الدوائر، والمستطيلات.
- **إدارة بصرية مرنة**: شريط أدوات جانبي مستقبلي مدمج وقابل للطي بالكامل (`☰`) لتوسيع مساحة العمل.
- **معاينة حية فورية**: إلغاء الأكواد النصية وحقن النتائج البصرية مباشرة في متصفح المستخدم (Live DOM Injection).
- **بدون سيرفر خلفي (No-Backend)**: أمان وخصوصية كاملة، يتم الاتصال مباشرة من متصفحك إلى API.

## 🛠️ طريقة التشغيل المحلية
1. قم بعمل `Clone` للمستودع.
2. افتح ملف `index.html` مباشرة في أي متصفح.
3. أدخل مفتاح الـ API الخاص بك وابدأ الابتكار.
